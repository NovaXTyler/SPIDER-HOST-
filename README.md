- ✅ **ZIP/GitHub Hosting** – Upload ZIP files or host GitHub repos directly
- ✅ **4 Hosting Plans** – Free (3 bots), Plan10 (₹50/10 bots), Plan20 (₹180/20 bots), Unlimited (₹350/unlimited)

## ⚙️ Configuration (Railway/Heroku)

Set these environment variables in your deployment platform:

| Variable | Description | Required |
|----------|-------------|----------|
| `BOT_TOKEN` | Telegram Bot Token from @BotFather | ✅ Yes |
| `OWNER_ID` | Your Telegram User ID | ✅ Yes |
| `OWNER_ID_2` | Secondary Owner ID | Optional |
| `ADMIN_ID` | Admin User ID | Optional |
| `YOUR_USERNAME` | Owner 1 Telegram Username | Optional |
| `YOUR_USERNAME_2` | Owner 2 Telegram Username | Optional |
| `CHANNEL_ID` | Telegram Channel ID (-100...) | Optional |
| `CHANNEL_NAME` | Channel Display Name | Optional |
| `CHANNEL_LINK` | Channel Invite Link | Optional |
| `UPI_ID` | UPI ID for Payments | Optional |
| `GITHUB_TOKEN` | GitHub Personal Access Token | Optional |
| `BACKUP_CHANNEL_ID` | Backup Channel ID | Optional |
| `WELCOME_IMAGE_URL` | Welcome GIF/Image URL | Optional |
| `MAIN_LINK_URL` | Main Link URL | Optional |
| `MAIN_LINK_TEXT` | Main Link Button Text | Optional |

## 🚀 Deployment

### Railway
1. Fork or upload this repository to GitHub
2. Go to [Railway.app](https://railway.app) → "Deploy from GitHub"
3. Set environment variables above
4. Deploy!

### Local
```bash
pip install -r requirements.txt
python bot.py
```
